\chapter{Déclaration d'utilisation de l'intelligence artificielle générative}
\label{chap:annexe-ia}

Conformément aux lignes directrices des Études supérieures et postdoctorales de l'Université de Montréal, et en accord avec mon directeur de recherche, je déclare ci-dessous l'utilisation d'outils d'intelligence artificielle générative dans la réalisation de ce mémoire.

\bigskip 

\textit{Outils d'intelligence artificielle} : Claude (Anthropic), diverses versions, utilisé par l'interface conversationnelle et par l'outil de programmation Claude Code, de septembre 2025 à septembre 2026 ;

\textit{Exécution} : Claude Code a servi à rédiger certains scripts de soumission des calculs sur les grappes de Calcul Québec ;

\textit{Visualisation} : Claude Code a servi à écrire les scripts de post-traitement de certaines figures, dont j'ai vérifié la cohérence ;

\textit{Analyse} : Claude Code a servi à écrire des scripts de post-traitement produisant certaines valeurs rapportées dans le texte, dont j'ai vérifié les résultats ;

\textit{Rédaction -- révision et édition} : Claude a servi à la relecture de la notation et de la cohérence entre les chapitres, ainsi qu'à la correction de la langue. Claude Code a appliqué, sur mes instructions, les corrections mécaniques au code source \LaTeX{}. Claude a reformulé certains de mes propos pour améliorer la lisibilité ;

\textit{Rédaction -- traduction} : Claude a traduit le résumé en anglais, que j'ai révisé par la suite.

\bigskip

Le contenu scientifique, les dérivations, les calculs, ainsi que l'analyse et l'interprétation des résultats sont les miens. J'ai vérifié tout contenu produit ou proposé par ces outils et j'en assume l'entière responsabilité.
